Philosophy

不只是检测，是调查

传统 NIDS 规则命中就告警。3Monkeys Sentinel 让 LLM 像安全分析师一样自主调查可疑流量，并把整个推理过程可视化。

维度传统 IDS/IPSAI 检测工具3Monkeys Sentinel
LLM 角色无分类器决策者（思考→行动→观察→再思考）
分析方式规则匹配单包单次分类多步关联调查，自主决定路径
响应能力阻断/告警只能告警封禁/隔离/通知/生成报告
记忆能力无无三层记忆，跨事件关联
自主性被动匹配被动分类主动调查 + 主动响应
Architecture

双层检测架构

规则引擎做第一道快筛（<1ms/包），只把疑似威胁送入 Agent 深度调查（500ms~3s），性能与深度兼顾。

网卡流量 (~1000+ 包/秒) │ ▼ ┌──────────────────────────────────────────────┐ │ 第一层：规则引擎 (快筛, <1ms/包) │ │ 正则匹配 + 威胁情报本地缓存 │ │ ├── 命中 → 直接告警 (SQLi/XSS/命令注入) │ │ ├── 正常 → 放行 │ │ └── 疑似 → 送入 Agent │ └──────────────┬───────────────────────────────┘ │ ~5% 流量 ▼ ┌──────────────────────────────────────────────┐ │ 第二层：Agent 自主调查 (500ms~3s) │ │ Think → Act → Observe → Think → ... → Respond │ │ • LLM 自主决定调查路径 │ │ • 调用 14 个工具收集/关联/响应 │ │ • 三层记忆关联历史事件 │ │ • 输出结构化决策 + 响应动作 │ └──────────────────────────────────────────────┘
⚡

规则引擎（快）

正则匹配 + Suricata 语法兼容，处理 95% 流量，<1ms 完成判断。社区规则可直接复用。

ScapyRegex
🧠

Agent 调查（深）

LangGraph 推理循环，LLM 自主决定调查路径。面对不同威胁，调查路径不同。最多 10 步。

LangGraphQwen2.5-7B
🛡️

主动响应

封禁 IP、封禁域名、通知用户、生成事件报告。白名单保护，默认半自动模式。

FirewallAudit

Model Pipeline

完整模型 Pipeline

数据标注 → LoRA 微调 → 量化压缩 → 端侧部署。训推分离：云端训练，端侧推理，零边际成本。

1

数据标注

远程 72B 大模型自动标注 → 人工抽检校验（20%）。Alpaca 格式 500-1000 条安全领域指令对，覆盖 9 种攻击场景 + 数据增强。

Auto LabelAlpacaAugment
2

LoRA 微调

Qwen2.5-7B-Instruct 基座，rank=16 / alpha=32 / dropout=0.05，3-5 epoch + 早停防过拟合。输出 adapter weights ~50MB。

PEFTrank=16Early Stop
3

量化压缩

Q4_K_M 4-bit 量化，GGUF 格式。模型体积 14GB → 4.5GB（-69%），精度损失 < 2%，推理速度提升 50%。

Q4_K_MGGUFllama.cpp
4

端侧部署

Ollama 加载 GGUF（默认）/ llama.cpp 直接推理（备选）。内存占用 ~5GB，推理延迟 2-5s/次，普通笔记本可跑。
