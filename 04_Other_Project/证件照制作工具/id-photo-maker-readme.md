## 工具概述

证件照制作工具是一款基于纯前端技术实现的在线证件照生成器。用户上传任意照片后，系统会自动识别并去除背景，然后根据选择的尺寸规格和背景颜色生成标准证件照。整个过程无需上传到服务器，所有处理均在浏览器本地完成，保护用户隐私。

工具采用轻量化极简界面，以系统字体、清晰分区和少量交互完成整个流程，不加载远程字体、模型或脚本。

## 核心功能

### 功能概览

| 功能 | 说明 |
|------|------|
| 上传照片 | 支持 JPG/PNG，单张不超过 20 MB，建议使用纯色背景照片 |
| 自动抠图 | 基于 Flood Fill 算法的智能背景识别，自动去除背景并替换 |
| 多规格尺寸 | 支持 1 寸、标准 2 寸、小二寸、大一寸四种常用规格 |
| 背景颜色 | 白底、蓝底、红底、黑底四种背景色自由切换 |

### 自动抠图

系统采用增强版 Flood Fill（洪水填充）算法进行背景识别和去除。算法从图片边缘采样背景颜色，然后从四周边界向内扩散，将与背景色相近的区域标记为背景并设为透明。

为提高抠图质量，算法引入了多项优化措施：

- **中位数采样**：从 16 个边缘采样点取中位数作为背景色基准，抗噪能力优于平均值
- **背景蒙版收缩**：保留人物边缘细节，降低浅色衣物和发丝被直接切掉的概率
- **颜色去溢出**：将半透明边缘像素沿远离背景色方向修正，消除发丝边缘的蓝/绿色溢出
- **边缘羽化**：使用半径 2px 的 Box Blur 平滑边缘，避免硬切造成的锯齿感

### 智能定位

上传照片后，系统会检测非透明前景的包围盒，再计算基础缩放和居中位置。它不是人脸或五官检测，因此正式证件仍需人工检查头顶留白、眼睛位置和肩部范围。

### 实时预览与调整

- **抠图容差滑块**：拖动可实时预览抠图效果，200ms 防抖避免频繁重计算
- **缩放滑块**：调整人物在证件照中的大小比例
- **拖拽定位**：在预览图上直接拖拽调整人物位置

### 下载输出

- **下载证件照**：导出按 300 DPI 尺寸换算得到的像素图；PNG 本身不额外写入 DPI 元数据
- **下载排版照**：生成 6 寸相纸排版（1200×1800px），自动排列多张证件照并添加裁切线，可直接送照相馆冲印

## 规格说明

### 支持的证件照尺寸

工具支持以下四种标准证件照规格，像素分辨率均按照 300 DPI 计算：

| 规格名称 | 厘米尺寸 | 像素分辨率 | 主要用途 |
|----------|----------|------------|----------|
| 1 寸 | 2.5 × 3.5 cm | 295 × 413 px | 常见报名照、工牌 |
| 标准 2 寸 | 3.5 × 5.3 cm | 413 × 626 px | 入职简历、档案存档 |
| 小二寸 | 3.3 × 4.8 cm | 390 × 567 px | 常见护照/报名规格，以通知为准 |
| 大一寸 | 3.3 × 4.5 cm | 390 × 531 px | 港澳通行证 |

> **关于分辨率**：上述像素按 1 cm ≈ 118.11 像素换算。不同机构对尺寸、背景、文件体积和头部比例的要求可能不同，提交前必须核对当次通知。

### 背景颜色

工具提供四种常用背景色：

| 颜色 | 色值 | 适用场景 |
|------|------|----------|
| 白底 | #FFFFFF | 最通用，常见于报名、工牌及部分证件材料 |
| 蓝底 | #438EDB | 部分报名、档案或单位材料 |
| 红底 | #D9001B | 部分保险、档案或单位材料 |
| 黑底 | #000000 | 非标准用途，适用于艺术照或特殊需求 |

## 技术实现

### 技术栈

- **纯前端**：HTML + CSS + JavaScript，无后端依赖
- **Canvas API**：用于图像处理和渲染
- **Object URL API**：避免把大图转成 Base64 后再读取，降低额外内存占用
- **CSS Variables**：主题色和样式管理

### 核心算法流程

```
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 图片加载与缩放                                       │
│  上传图片后，将其缩放至最大 800px 进行处理，提高运算速度          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 2: 背景色采样                                          │
│  从图片四角和边缘中点共 16 个位置采样，取中位数作为背景色基准      │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 3: Flood Fill 标记                                     │
│  从四周边界像素出发，向内扩散标记与背景色相近的区域为背景           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 4: 背景蒙版收缩                                        │
│  收缩 1 像素后再羽化，减少人物浅色边缘被直接误删                    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 5: 边缘羽化                                            │
│  使用半径 2px 的 Box Blur 平滑边缘，生成连续透明度值              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 6: 颜色去溢出                                          │
│  将半透明像素的颜色沿远离背景色方向修正，消除边缘色偏               │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 7: 前景检测与定位                                       │
│  检测前景人物包围盒，计算最佳缩放和居中位置                        │
└─────────────────────────────────────────────────────────────┘
```

### 性能优化

- **图片缩放**：将原始图片缩放至最长边 800px 后处理，大幅减少运算量
- **有界队列**：Flood Fill 使用定长 TypedArray 队列，每个像素最多入队一次
- **防抖处理**：容差滑块使用 200ms 防抖，避免拖动时频繁重计算
- **采样间隔**：前景检测时每 2 像素采样一次，进一步加速
- **Blob 下载**：使用 `canvas.toBlob()` 导出，避免 Base64 带来的内存膨胀

### 算法局限性

> **注意**：本工具采用的 Flood Fill 算法基于颜色连通性，对背景复杂的照片（如户外、渐变背景、花哨背景）效果有限。适合处理**纯色背景**的证件照。如需更高精度的抠图效果，建议使用基于 AI 模型的专业工具（如 U²-Net、MODNet 等）。

此外，本工具不做人脸关键点检测，无法自动校验眼睛高度、头部占比、姿态、阴影、服装或官方合规性；“自动定位”只依据前景包围盒。

## 使用说明

### 基本流程

1. 打开工具页面，点击或拖拽上传照片
2. 系统自动抠图并生成预览
3. 选择目标尺寸和背景颜色
4. 使用滑块调整抠图容差和缩放比例
5. 在右侧预览图上拖拽调整人物位置
6. 点击「下载证件照」或「下载排版照」

页面会提示未识别到前景、背景保留过多、前景误删风险、文件格式错误等情况；出现警告时先调整容差再下载。

### 抠图容差调整

抠图容差控制背景去除的范围。数值越大，去除范围越广；数值越小，去除范围越窄。

| 情况 | 表现 |
|------|------|
| 容差过小 | 可能残留背景，尤其是边缘区域 |
| 容差过大 | 可能误删人物边缘（如浅色衣服、发丝） |
| 建议 | 从默认值 35 开始，根据实际效果微调 |

### 排版照使用

「下载排版照」功能生成一张 6 寸相纸排版（1200×1800px），上面排列多张证件照并带有裁切线。这张图片可以直接发送给照相馆进行冲印，无需额外处理。

不同规格的排版数量：

| 规格 | 排版数量 |
|------|----------|
| 1 寸 | 4×4 = 16 张 |
| 标准 2 寸 | 2×2 = 4 张 |
| 小二寸 | 3×3 = 9 张 |
| 大一寸 | 3×3 = 9 张 |

## 注意事项

### 照片选择建议

- **背景纯色**：纯色背景的抠图效果最佳，避免复杂背景
- **人物居中**：上传前尽量让人物位于照片中央
- **光线均匀**：避免强烈的阴影和高光区域
- **衣着对比**：穿着与背景颜色反差较大的衣服，便于抠图

### 隐私说明

> **隐私保护**：本工具为纯前端实现，不加载远程字体、脚本或模型，所有图像处理均在浏览器本地完成，图片不会上传到服务器。

### 合规性提示

本工具生成的证件照仅供个人非正式用途参考。如需用于正式证件（护照、身份证、签证等），请以相关部门的实际要求为准，必要时请前往专业照相馆拍摄。

### 浏览器兼容性

- 推荐使用 Chrome、Firefox、Safari、Edge 等现代浏览器
- 不支持 IE 浏览器
- 移动端浏览器也可正常使用
