# Three Monkeys Toolbox · 设计文档站

品牌「Three Monkeys Toolbox」的项目门户 HTML 页面,用单文件展示整个工具箱的设计理念、模块构成与项目间的关系。

## 内容

- `three-monkeys-toolbox.html` — 单文件设计文档(深色主题 + Mermaid 流程图)
- `assets/architecture_hero.jpg` — Hero 区架构示意图
- `_shared/js/mermaid.min.js` — 内置 Mermaid(离线渲染)
- `three-monkeys-toolbox.zip` — 整站打包,可直接发送他人离线浏览

## 设计理念

呼应品牌「三不猴」:
- 🙈 Mizaru(见不恶魔)— 流量检测
- 🙉 Kikazaru(听不恶魔)— 通信分析
- 🙊 Iwazaru(说不恶魔)— 数据保护

## 使用

直接用浏览器打开 `three-monkeys-toolbox.html` 即可。Mermaid 流程图走本地 JS 渲染,无外网依赖。

## Trae Share

仓库内的 `.trae-html-share-packages/` 是 Trae IDE 生成的分享包,与 `three-monkeys-toolbox.html` 内容一致。
