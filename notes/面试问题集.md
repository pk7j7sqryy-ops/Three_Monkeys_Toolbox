## 一、Python

**Q1: PyCharm 中 pip 与 conda 安装的包有什么区别，作用范围如何确定？** `2026-07-30`
> - 包能否被项目导入，最终取决于 PyCharm 选中的 Python 解释器及其环境前缀；使用 `python -m pip` 可确保 pip 对应当前解释器，pip 装进 conda 环境后也只在该环境中生效。
> - `conda install` 把软件安装到指定 conda 环境（`base` 也只是一个 conda 环境）；其他系统 Python、venv 或 conda 环境默认都看不到这些包。
> - pip 主要管理 Python distribution，wheel 可以包含编译扩展和部分原生运行库，但 pip 不是通用系统依赖管理器；conda 还能统一管理 Python、C/C++ 库、可执行程序和环境级依赖。
> - 现代 pip 已支持依赖回溯，不能简单说成“顺序安装”；混用时仍应先用 conda 安装尽可能多的依赖，再用当前环境的 pip 补充，并避免之后继续用 conda 大幅改动该环境。
> - 关键词：`sys.executable`、`sys.prefix`、`python -m pip --version`、`pip show`、`conda list`、`site-packages`

## 八、深度学习

**Q1: 为什么 `torchsummary` 统计模型参数时会报 `'int' object has no attribute 'numpy'`？** `2026-07-30`
> - 直接调用子模块的 `.forward()` 会绕过 `nn.Module.__call__()` 及其 forward hook，而 `torchsummary` 依赖 hook 收集各层信息，因此应写成 `self.linear1(x)`。
> - 当所有层都绕过 hook 后，`torchsummary` 没有捕获到参数，`total_params` 保持为 Python 整数 `0`；旧版实现继续调用 `.numpy()`，于是产生这个误导性异常。
> - 修正子模块调用即可解决当前代码的问题；也可改用原项目推荐的新版本 `torchinfo.summary`。
> - 模型代码还应使用 `__init__`、`__name__ == '__main__'`，并避免连续调用两次等价的 ReLU。
> - 关键词：`torchsummary`、forward hook、`nn.Module.__call__()`、`.forward()`、`torchinfo`

**Q2: `torchsummary` 的 `input_size`、`batch_size` 与真实输入批量有什么区别？** `2026-07-30`
> - `x = torch.randn(10, 3)` 中的 `10` 是模型实际接收的样本数，而 `summary()` 独立运行一次模拟前向传播，不读取也不修改这个真实输入。
> - `input_size=(3,)` 描述单条样本去掉 batch 维后的形状，因此与真实输入 `(10, 3)` 正确对应；图像 `(N, 3, 224, 224)` 则写作 `(3, 224, 224)`。
> - 经典 `torchsummary` 内部固定创建 batch 为 `2` 的假输入以兼容 BatchNorm，传入的 `batch_size` 并不决定实际模拟输入的 batch。
> - `batch_size` 主要替换结果表中的 batch 维并参与内存估算：默认 `-1` 显示 `[-1, 4]`，传入 `111` 则显示 `[111, 4]`；参数量和真实训练过程不受影响。
> - 关键词：`torchsummary`、`input_size`、`batch_size`、batch 维、模拟前向传播

**Q3: 为什么调用 `torch.load()` 后模型前后两次预测仍完全相同？** `2026-07-30`
> - `nn.Linear` 的权重和偏置只在模型构造时随机初始化一次，同一个模型实例不会在每次前向传播时重新随机初始化。
> - `torch.load()` 只把磁盘内容反序列化为内存中的 `state_dict`，不会自动修改模型；还必须调用 `model.load_state_dict(state_dict)`，而题目代码中的这一行被注释掉了。
> - 两次输入 `x` 和 `x_new` 数值相同，模型参数也没有变化，且网络不含 Dropout 等随机层，因此两次输出必然相同。
> - 正确推理顺序是 `torch.load(..., map_location=device, weights_only=True)`、`model.load_state_dict(...)`、`model.eval()`，再在 `torch.inference_mode()` 中预测；若文件保存的本来就是当前参数，加载后输出仍可相同。
> - 关键词：`torch.load`、`state_dict`、`load_state_dict`、随机初始化、`eval()`、`inference_mode()`
